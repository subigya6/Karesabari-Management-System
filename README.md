# Karesabari-Management-System
Karesabari Management System is a Python app that makes traditional Nepali kitchen gardening super easy for city folks! 🌿 It sends smart watering &amp; harvest reminders ⏰, diagnoses plant problems 🩺, and gives quick care tips for crops like *rayo ko saag* &amp; tomatoes 🍅—so you can grow fresh veggies at home without the stress! 🥦✨
